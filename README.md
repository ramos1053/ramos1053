## Hi, I'm Alan

I build small, focused tools for macOS and Windows. Most of them started because something in my own day was slower than it should have been, and the fix turned into an app.

Everything here is MIT licensed. Every repo has a contributing guide, so pull requests are welcome.

### macOS

| Project | What it does |
|---------|--------------|
| [Snipster](https://github.com/ramos1053/Snipster) | A menu bar snippet manager with keyboard triggers, fill-in templates and a quick-access window you open with a hotkey. |
| [Restless](https://github.com/ramos1053/Restless) | Keeps your Mac awake and stops the screen from locking. It can also keep a chosen app active in the background. |
| [MPP Viewer](https://github.com/ramos1053/MPP-Viewer-Mac) | Opens and edits Microsoft Project files, with Gantt, timeline, network, calendar and resource views. [Screenshots and download.](https://ramos1053.github.io/MPP-Viewer-Mac/) |

### Windows

| Project | What it does |
|---------|--------------|
| [Snipster for Windows](https://github.com/ramos1053/Snipster-Windows) | The same snippet manager as a tray app, written from scratch against Win32 and WPF. |
| [NetDrive Tray](https://github.com/ramos1053/NetDrive-Tray) | Maps network drives from the system tray using a smartcard, a password or your current Windows login. |

### Everything else

[RamosTech](https://github.com/ramos1053/RamosTech) holds the projects that don't have their own repo yet: GottaGo for iOS, plus Tabby, PIP, Nimbus-Swift and Time Machine Manager for macOS.

### Getting involved

Bug reports and pull requests are welcome on any of these. Each repo has a `CONTRIBUTING.md` with the details, and security problems can be reported privately from the repo's Security tab.
